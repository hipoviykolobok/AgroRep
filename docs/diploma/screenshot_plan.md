# План скриншотов для главы 3

План отражает текущую версию MVP. Для финальной верстки рекомендуется делать скриншоты после заполнения справочников, создания demo-наборов через мастер и загрузки файлов из `sample_data/`.

## Основные скриншоты

| N | Экран | Что должно быть видно | Подпись |
|---|---|---|---|
| 1 | Swagger UI `http://localhost:8000/docs` | Полный список FastAPI endpoints, включая `make-current` и `DELETE` endpoints | Рисунок 3.1 - Документация API MVP-прототипа |
| 2 | Streamlit, страница `Вход` | Форма входа, demo email/password, кнопка seed | Рисунок 3.2 - Экран авторизации пользователя |

## Что важно не забыть

- Скриншоты должны соответствовать локальному адресу `http://localhost:8502`.
- В финальной главе не оставлять технические плейсхолдеры для рисунков.
- Для демонстрации лучше использовать три sample-файла из `sample_data/`.
- Скриншот тестов должен показывать актуальный результат `10 passed`.
- Если демонстрируется удаление, нужно явно указать, что это административная функция MVP и что soft delete не реализован.
